## Engineering principles

I prefer systems that are inspectable and honest about their evidence:

- Keep secrets and personal data out of source control.
- Make preprocessing, assumptions, splits, and metrics reproducible.
- Fail closed when a model or dependency is unavailable.
- Separate simulated/demo data from live or production data.
- Treat monitoring, security, accessibility, and documentation as part of delivery.
